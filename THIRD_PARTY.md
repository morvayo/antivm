# third party material

[vmprotect sources](https://github.com/morvayo/VMProtect3.5.1/tree/73196d341d04a2e15b4746a9b93efba5326eff53)

affected code is in src/virtual src/debug and the legacy firmware access path
in src/physical/firmware.hpp

the project owner reports having permission to use this material
no upstream license granting redistribution rights was verified
this material is excluded from the mit grant for original contributions
the mit license alone does not license the whole combined library

parsers and are not relicensed by this project
